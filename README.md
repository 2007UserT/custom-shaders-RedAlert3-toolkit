**Toolkits for NordLicht Custom Red Alert 3 PBR Shader**


Contains:


*Compiled .fxo files that could be straightly put into your mod

*Blender plugin that customized for NordLicht Shader(Blender Version 5.0.1,or most versions between 4.4 and 5.0)

*Adobe Substance 3D Painter document template

*Substance 3D Painter export template for shader ObjectsSoviet or other Objects shader

*Substance 3D Painter export template for buildings(use Objects shader)

*Original Chinese Readme document

*Manually Translated English Readme document
